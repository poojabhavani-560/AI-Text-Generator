# AI-Text-Generator

A simple and beginner-friendly web application that generates text using Generative AI based on user input.

## Overview

This project allows users to enter a topic and instantly receive AI-generated content. It demonstrates how to integrate a Generative AI API into a basic web interface using JavaScript.

## Features

* Enter any topic or keyword
* Generate AI-based text instantly
* Simple and clean user interface
* Fast and responsive

## How It Works

User enters a topic → Clicks generate → Request is sent to AI API → AI returns text → Output is displayed

## Tech Stack

* HTML
* CSS
* JavaScript
* Generative AI API (OpenAI / Gemini / HuggingFace)

## Setup Instructions

1. Clone the repository

```
git clone https://github.com/your-username/ai-text-generator.git
```

2. Open the project folder

```
cd ai-text-generator
```

3. Add your API key in `script.js`

```
Authorization: Bearer YOUR_API_KEY
```

4. Open `index.html` in your browser

## Example Usage

Input:

```
AI in education
```

Output:
